## v1.1 Requirements

### Coverage Audit

- [x] **COV-01**: Coverage tool measures line/branch coverage across all modules and outputs per-module report

### Unit Tests

- [x] **UNIT-01**: Governance scripts have test coverage (scaffold, health-check, install-plugins)

- [x] **UNIT-03**: Hook behavior tested (lifecycle events, matcher patterns, exit code handling)
- [x] **UNIT-04**: Uncovered command handlers identified and tested

### Integration Tests

- [x] **INTG-01**: End-to-end flow tested: fresh install through /prime -> /gsd:plan-phase -> /gsd:execute-phase -> /gsd:verify-work
- [x] **INTG-02**: Governance hook enforcement scenarios validated (docs check, secrets scan, branch protection)
- [x] **INTG-03**: Plugin loading and command routing integration verified across plugin types

### CI Pipeline

- [x] **CI-01**: base64-scan.sh timeout on large diffs fixed (binary file exclusion)
- [x] **CI-02**: Coverage reporting integrated into CI pipeline
- [x] **CI-03**: All CI checks pass on Linux, macOS, and Windows
