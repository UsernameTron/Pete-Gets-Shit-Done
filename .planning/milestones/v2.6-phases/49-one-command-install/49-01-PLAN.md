Create `bin/setup-from-clone.js` as a zero-dependency CommonJS Node.js script (per D-05). The script orchestrates a fresh-clone-to-working-install flow. Uses `execFileSync` (not `exec`) for all subprocess calls — no shell injection risk.

**Structure:**

1. **Preamble**: `#!/usr/bin/env node`, `'use strict'`, require `fs`, `path`, `os`, `child_process` (execFileSync only). Define color constants matching install.js style: `cyan='\x1b[36m'`, `green='\x1b[32m'`, `yellow='\x1b[33m'`, `red='\x1b[31m'`, `dim='\x1b[2m'`, `reset='\x1b[0m'`, `bold='\x1b[1m'`.

2. **Constants**: `PROJECT_ROOT = path.resolve(__dirname, '..')`, `HOME = os.homedir()`, paths for `CLAUDE_COMMANDS_DIR = path.join(HOME, '.claude', 'commands', 'gsd')`, `CLAUDE_HOOKS_DIR = path.join(HOME, '.claude', 'hooks')`, `CLAUDE_SETTINGS = path.join(HOME, '.claude', 'settings.json')`. Also define the 6 hook file names: `['gsd-check-update.js', 'gsd-config-protection.js', 'gsd-context-monitor.js', 'gsd-cost-tracker.js', 'gsd-prompt-guard.js', 'gsd-statusline.js']`.

3. **Step tracking**: Array `results = []` to collect `{ step, status, detail }` objects where status is `'pass'`, `'skip'`, `'fail'`, or `'warn'`. Function `record(step, status, detail)` that pushes to results and logs inline with colored status.

4. **Step 1 — npm install** (per D-03, INST-02): Check if `node_modules` directory exists AND `node_modules/.package-lock.json` exists. If both exist AND `fs.statSync('package.json').mtimeMs <= fs.statSync('node_modules/.package-lock.json').mtimeMs`, record skip with "node_modules up to date" (per D-08, D-09). Otherwise run `execFileSync('npm', ['install'], { cwd: PROJECT_ROOT, stdio: 'inherit' })`. Wrap in try/catch — on failure, record fail and `process.exit(1)` (per D-13, critical step).

5. **Step 2 — Build hooks** (prerequisite for install): Run `execFileSync(process.execPath, [path.join(PROJECT_ROOT, 'scripts', 'build-hooks.js')], { cwd: PROJECT_ROOT, stdio: 'inherit' })`. On failure, record fail and exit(1) (critical — hooks must build before install).

6. **Step 3 — Run installer** (per D-04, INST-03/04/05): Run `execFileSync(process.execPath, [path.join(PROJECT_ROOT, 'bin', 'install.js'), '--claude'], { cwd: PROJECT_ROOT, stdio: 'inherit' })`. This handles symlinks, hooks, plugin registration. On failure, record fail and exit(1) (critical).

7. **Step 4 — Copy injection-patterns.json** (per INST-06): Source is `path.join(PROJECT_ROOT, 'lib', 'injection-patterns.json')`. Destination is `path.join(HOME, '.claude', 'get-shit-done', 'bin', 'lib', 'injection-patterns.json')`. If source and dest exist and content is identical (compare with `fs.readFileSync` then Buffer.equals), record skip "injection-patterns.json already current" (per D-09). If dest doesn't exist or content differs, `fs.mkdirSync` the parent recursively, `fs.copyFileSync`, record pass (per D-10). On error, record warn (non-critical per D-14) and add to collected failures.

8. **Verification phase** (per D-06, D-07):
   - Count `.md` files in `CLAUDE_COMMANDS_DIR` — compare against count of `.md` files in `path.join(PROJECT_ROOT, 'commands', 'gsd')`. Record pass/fail with counts.
   - Check each of the 6 hook files exists in `CLAUDE_HOOKS_DIR`. Record pass with count or fail listing missing hooks.
   - Read `CLAUDE_SETTINGS`, parse JSON, check `enabledPlugins` object has a key containing `get-shit-done` (partial match on key name). Record pass/fail.
   - Check `injection-patterns.json` exists at installed location. Record pass/fail.

9. **Results table** (per D-07, D-11): Print a table with columns `Step | Status | Detail`. Use fixed-width formatting. Color `PASS` in green, `SKIP` in yellow, `FAIL` in red, `WARN` in yellow. After the table, print summary: "N passed, N skipped, N failed, N warnings".

10. **Exit code**: If any result has status `'fail'`, `process.exit(1)`. Otherwise `process.exit(0)` (per INST-01).

**Idempotency rules** (per D-08 through D-12):
- npm install: skip if node_modules fresh (mtime comparison)
- build-hooks: always run (fast, ensures dist is current)
- install.js --claude: always run (it has its own idempotency)
- injection-patterns.json: skip if content matches (Buffer.equals)
