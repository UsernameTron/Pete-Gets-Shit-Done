## Security Critical (P1+P2)

- [ ] **SEC-01**: Replace predictable temp paths (`gsd-${Date.now()}.json`) with cryptographic nonces (`crypto.randomBytes(8).toString('hex')`) in core.cjs `output()`
- [ ] **SEC-02**: Fix path containment bypass in security.cjs `validatePath()` — append `path.sep` before `startsWith` comparison to prevent sibling directory escape

## Shell & Output Hardening (P3+P4)

- [ ] **SEC-03**: Block shell metacharacters (`;`, `|`, `>`, `<`, `&`, newlines, `~user`) in security.cjs `validateShellArg()`
- [ ] **SEC-04**: Add `__GSD_TRUNCATED__` sentinel marker when output fallback truncates data in core.cjs `output()`

## Test Coverage (P5)

- [ ] **SEC-05**: Increase branch coverage from 77% to 85%+ targeting security-critical paths (validatePath, validateShellArg, output, writeStateMd)

## Config Migration (P6)

- [ ] **SEC-06**: Add config version tracking and migration system to config.cjs for forward-compatible settings evolution
