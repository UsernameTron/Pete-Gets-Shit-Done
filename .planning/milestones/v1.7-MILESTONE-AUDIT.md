## Architecture Decisions

1. **Zero-dependency testing**: All tests use `node:test` + `node:assert/strict` — no jest, mocha, or vitest
2. **`execFileSync` over `execSync`**: Shell injection safety (SEC-01)
3. **Crypto-random temp dirs**: `crypto.randomBytes(8).toString('hex')` for all fixtures
4. **macOS symlink handling**: `fs.realpathSync(os.tmpdir())` throughout
5. **`childTestEnv()` helper**: Strips `NODE_TEST_CONTEXT` for reliable child process test execution
6. **`runGsdToolsSafe` pattern**: try/catch wrapper for expected failures
7. **Fixture factory system**: `createEmptyProject()`, `createMidMilestoneProject()`, `createCompletedMilestoneProject()`, `createCorruptProject(type)` for consistent test state
