Create `get-shit-done/bin/lib/uat-patterns.cjs` as a **pure function module** (no requires from other GSD modules — it is a leaf node at Layer 3 with no intra-project dependencies).

Implement a `patterns` array with at least these 8 named patterns:

1. **file_exists** — regex: `/(\S+)\s+(?:exists|should exist|must exist)/i` — command: `test -f "{path}" && echo "present" || echo "absent"` — expected: `present` — compare: `equals`

2. **file_not_exists** — regex: `/(\S+)\s+(?:does not|should not|must not)\s+exist/i` — command: `test ! -f "{path}" && echo "absent" || echo "present"` — expected: `absent` — compare: `equals`

3. **test_suite_green** — regex: `/(?:npm test|test suite)\s+pass|all tests (?:green|pass)|(\d+)\s+tests?\s+pass/i` — command: `npm test 2>&1 | tail -3` — expected: `# fail 0` — compare: `contains`

4. **coverage_threshold** — regex: `/coverage\s*(?:>=?|above|at least)\s*(\d+)%/i` — command: `npm run test:coverage 2>&1 | grep "All files" | awk '{print $4}'` — expected: captured number — compare: `gte`

5. **file_contains** — regex: `/(\S+)\s+(?:contains?|includes?)\s+"([^"]+)"/i` — command: `grep -c "{pattern}" "{file}"` — expected: `0` — compare: `gt` (count > 0 means found)

6. **file_not_contains** — regex: `/(\S+)\s+does not contain\s+"([^"]+)"/i` — command: `grep -c "{pattern}" "{file}" 2>/dev/null || echo "0"` — expected: `0` — compare: `equals`

7. **files_identical** — regex: `/(\S+)\s+and\s+(\S+)\s+are\s+(?:byte-)?identical/i` — command: `diff "{file1}" "{file2}" > /dev/null 2>&1 && echo "identical" || echo "different"` — expected: `identical` — compare: `equals`

8. **module_export_count** — regex: `/(\S+\.(?:cjs|js|mjs))\s+(?:contains?|has|exports?)\s+(\d+)\s+(?:entries|exports?|keys|items|functions)/i` — command: `node -p "Object.keys(require('./{file}')).length"` — expected: captured number — compare: `equals`

Implement `matchPattern(mustHaveText)` that iterates the patterns array, tries each regex, and returns the first match as `{ pattern: name, assertion: generate(match), original: text }`. If no pattern matches, return `{ pattern: null, assertion: null, original: text }`.

**Read-only safety:** Every generated command must be verifiably read-only. No generated command may contain `>`, `>>`, `tee`, `rm`, `mv`, `cp`, or `truncate`. The diff command's output redirection to `/dev/null` uses `> /dev/null` which is only discarding output, not writing to a user file — this is acceptable.

Module exports: `{ patterns, matchPattern }`

Run tests — they MUST all pass (GREEN phase). Commit: `feat(54-01): implement uat-patterns with 8 pattern types`
