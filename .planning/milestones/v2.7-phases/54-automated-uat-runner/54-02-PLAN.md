Create get-shit-done/bin/lib/uat-runner.cjs at Layer 3 in the module architecture. It imports from Layer 2 (frontmatter.cjs, core.cjs) and Layer 3 peer (uat-patterns.cjs).

Implement three exported functions:

1. compareResult(actual, expected, mode):
   - 'equals': return actual === expected
   - 'contains': return actual.includes(expected)
   - 'gt': return parseFloat(actual) > parseFloat(expected)
   - 'gte': return parseFloat(actual) >= parseFloat(expected)
   - default: return actual === expected

2. runAutomatedUAT(planPaths):
   - Initialize results = { passed: [], failed: [], manual: [], total: 0 }
   - For each planPath in planPaths:
     - Read content with safeReadFile(planPath)
     - If no content, skip
     - Parse truths with parseMustHavesBlock(content, 'truths')
     - For each truth string:
       - Increment results.total
       - Call matchPattern(truth) from uat-patterns
       - If pattern is null: push to results.manual with { mustHave: truth, reason: 'No automated pattern match' }
       - If pattern matched: execute assertion.command via execSync with { encoding: 'utf8', timeout: 30000 }
         - On success: call compareResult(actual.trim(), assertion.expected, assertion.compare)
           - If pass: push { mustHave: truth, pattern: matched.pattern, actual: actual.trim() } to results.passed
           - If fail: push { mustHave: truth, pattern: matched.pattern, expected: assertion.expected, actual: actual.trim(), command: assertion.command } to results.failed
         - On error: push to results.failed with actual set to 'ERROR: ' + err.message and command = assertion.command
   - Return results

3. formatUATResults(results):
   - Build header line
   - For each passed item: line with checkmark and mustHave text
   - For each failed item: line with X and mustHave text, then Expected/Got/Command lines
   - For each manual item: line with ? and mustHave text + "manual verification needed"
   - Footer: "{passed.length} pass / {failed.length} fail / {manual.length} manual"
   - Return joined string

The execSync call MUST use timeout: 30000 (30 seconds) per UAT-09. Use require('child_process').execSync — not spawn or exec. The GSD codebase consistently uses execSync for synchronous command execution.

Module exports: { runAutomatedUAT, formatUATResults, compareResult }
