    ```
    CHECKPOINT_FILE = 'CHECKPOINT.json'
    CHECKPOINT_VERSION = 1
    STALE_THRESHOLD_MS = 24 * 60 * 60 * 1000

    writeCheckpoint(planningDir, overrides = {}):
      1. Read git state using execGit(['branch', '--show-current'], cwd) and execGit(['rev-parse', '--short', 'HEAD'], cwd)
         — wrap in try/catch, default to 'unknown' / '0000000' if not a git repo
      2. Read STATE.md from path.join(planningDir, 'STATE.md') using safeReadFile()
         Parse frontmatter with extractFrontmatter() to get milestone, phase number
         Extract phase_name from body using regex: /Phase:\s*.*?(\d+)\s*[-—]\s*(.+)/i or from frontmatter
      3. Determine phase directory, call scanPlanStatus(planningDir, phaseNum)
      4. Build checkpoint object matching CHECKPOINT.json schema
      5. Apply overrides via object spread: { ...checkpoint, ...overrides }
      6. Write JSON to path.join(planningDir, CHECKPOINT_FILE) with 2-space indent
      7. Return the checkpoint object

    readCheckpoint(planningDir):
      1. Build filePath = path.join(planningDir, CHECKPOINT_FILE)
      2. If file doesn't exist, return null
      3. Try JSON.parse — if fails, return null
      4. If data.version !== CHECKPOINT_VERSION, return null
      5. Calculate age = Date.now() - new Date(data.timestamp).getTime()
      6. Set data._stale = age > STALE_THRESHOLD_MS
      7. Set data._ageHours = Math.round(age / (60 * 60 * 1000))
      8. Return data

    scanPlanStatus(planningDir, phaseNum):
      1. Find phase directory: look in path.join(planningDir, 'phases') for directory matching phaseNum
         Use pattern: directory name starts with phaseNum + '-' (e.g., '52-checkpoint-engine')
      2. If directory not found, return { total: 0, completed: [], active: null, pending: [] }
      3. List files, filter for *-PLAN.md pattern, extract plan IDs (e.g., '52-01' from '52-01-PLAN.md')
      4. Filter for *-SUMMARY.md pattern, extract plan IDs similarly
      5. completed = plan IDs that also appear in summary IDs
      6. incomplete = plan IDs not in summary IDs
      7. active = incomplete[0] || null
      8. pending = incomplete.slice(1)
      9. Return { total: plans.length, completed, active, pending }
    ```
