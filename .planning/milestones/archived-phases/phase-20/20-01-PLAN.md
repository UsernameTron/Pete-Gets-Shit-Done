# Plan 20-01: Skills Extensibility

## Objective
Add skill composition support, SKILL.md metadata parsing, and dynamic skill discovery to the GSD skill registry. This is the foundational plan for Phase 20 — all other plans depend on these functions.

## Tasks

### Task 1: parseSkillMetadata(skillMdPath) in init.cjs
- Reuse `parseFrontmatter()` from `frontmatter.cjs` to parse SKILL.md YAML frontmatter
- Return structured object: `{ name, description, version, allowedTools, skills, model, userInvocable, raw }`
- Handle missing fields gracefully (return null/undefined per field, never throw)
- Handle missing/unreadable files (return `{ error: '...' }`)
- Pure function, no side effects

### Task 2: discoverSkills(projectRoot) in init.cjs
- Scan known directories for SKILL.md files:
  - `{projectRoot}/.claude/skills/*/SKILL.md`
  - `{projectRoot}/skills/*/SKILL.md`
  - `{projectRoot}/plugins/*/skills/*/SKILL.md` (plugin-bundled)
- Use `fs.readdirSync` + `fs.existsSync` (zero dependencies, sync)
- Return array of `{ path, name, metadata }` objects
- Each entry includes parsed metadata from Task 1
- Handle permission errors and missing directories gracefully

### Task 3: resolveSkillComposition(skillPath, projectRoot) in init.cjs
- Parse the `skills` frontmatter field (comma-separated skill names)
- Resolve each referenced skill name to a discovered skill path
- Return `{ resolved: [...paths], unresolved: [...names] }`
- Prevent circular references (track visited set, return error if cycle detected)
- Depth limit of 3 to prevent deep chains

### Task 4: querySkills(projectRoot, filter) in init.cjs
- Filter discovered skills by criteria: `{ name, hasVersion, agentType, userInvocable }`
- Return filtered array of skill metadata objects
- Wrapper around `discoverSkills()` + filter logic

### Task 5: Export new functions and wire CLI command
- Export `parseSkillMetadata`, `discoverSkills`, `resolveSkillComposition`, `querySkills` from init.cjs
- Add `skill-query` command to gsd-tools.cjs case statement
- `skill-query [--filter key=value]` — outputs discovered skills as JSON

### Task 6: Tests (12+ tests)
- `parseSkillMetadata`: valid SKILL.md, missing file, empty frontmatter, missing fields
- `discoverSkills`: finds skills in .claude/skills/, skills/, plugins/; handles missing dirs
- `resolveSkillComposition`: resolved refs, unresolved refs, circular detection
- `querySkills`: filter by name, filter by userInvocable

## Acceptance Criteria
