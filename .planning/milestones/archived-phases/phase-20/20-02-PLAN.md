# Plan 20-02: Orphaned Skills Audit

## Objective
Add an `audit-skills` command that scans all skill directories, cross-references with config, and reports orphaned, missing, or broken skills.

## Tasks

### Task 1: auditSkills(cwd) in init.cjs
- Call `discoverSkills(cwd)` from 20-01 to get all on-disk skills
- Load config via `loadConfig(cwd)` to get all `agent_skills` references
- Compute three categories:
  - **orphaned**: On disk but not referenced in any `agent_skills` config entry
  - **missing**: Referenced in config but SKILL.md not found on disk
  - **broken_refs**: Skills whose `skills` composition field references non-existent skills
- Return `{ orphaned: [...], missing: [...], broken_refs: [...], total_discovered, total_configured }`

### Task 2: Wire CLI command
- Add `audit-skills` case in gsd-tools.cjs
- Route to `init.cmdAuditSkills(cwd, raw)`
- Output: JSON (raw mode) or formatted table (default mode)
- Formatted output: section per category with counts

### Task 3: Tests (8+ tests)
- No orphans when config matches discovery
- Detects orphaned skill (on disk, not in config)
- Detects missing skill (in config, not on disk)
- Detects broken composition refs
- Empty config = all discovered skills are orphaned
- Empty discovery = all configured skills are missing
- Mixed scenario with all three categories

## Acceptance Criteria
- [ ] `auditSkills()` returns structured audit report
- [ ] `audit-skills` CLI command works in both raw and formatted modes
- [ ] Correctly classifies orphaned, missing, and broken_refs
- [ ] 8+ new tests, all passing
- [ ] No regressions
