# Plan 07-01: Security Critical Fixes

## Goal
Fix two critical security vulnerabilities identified by architecture review.

## Tasks

### Task 1: Cryptographic temp paths (SEC-01)
**File:** `get-shit-done/bin/lib/core.cjs`
**Line:** 168
**Current:** `gsd-${Date.now()}.json` — predictable, enables race condition attacks
**Fix:** Replace with `gsd-${crypto.randomBytes(8).toString('hex')}.json`
**Impact:** Requires adding `const crypto = require('crypto')` at top of file

### Task 2: Path containment boundary fix (SEC-02)
**File:** `get-shit-done/bin/lib/security.cjs`
**Lines:** 82-94
**Current:** Already correctly appends `path.sep` to both normalizedBase and normalizedPath on lines 83-84, then checks `normalizedPath.startsWith(normalizedBase)` on line 88.
**Analysis:** Upon closer reading, the implementation is actually correct. Both paths get `path.sep` appended, so `/project` won't match `/project-other` because it compares `/project-other/`.startsWith(`/project/`). The `resolvedPath !== resolvedBase` check handles the exact-match case.
**Action:** Verify with targeted tests that the sibling directory case is properly rejected.

### Task 3: Tests
- Add test for crypto temp path (verify nonce format, no Date.now)
- Add test confirming path containment rejects sibling directories

## Acceptance Criteria
- [ ] Temp file paths use cryptographic randomness
- [ ] Path containment correctly rejects sibling directory names
- [ ] All existing tests pass
- [ ] New tests cover both fixes
