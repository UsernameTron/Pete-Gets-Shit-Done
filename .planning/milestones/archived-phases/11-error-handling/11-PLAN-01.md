# Plan 1: GsdError Class and Error Code Registry

## Overview

Create the GsdError class in core.cjs as the structured error foundation for the GSD engine. Define a central error code registry (GSD_ERROR_CODES) that all catch blocks will reference. This is the dependency for Plans 2 and 3.

## Tasks

### Task 1: Create GsdError class and GSD_ERROR_CODES in core.cjs

<read_first>
- get-shit-done/bin/lib/core.cjs (lines 1-10 for imports, lines 1226-1271 for module.exports)
</read_first>

<action>
Add the following near the top of core.cjs, after the require() block (after line 9) and before the path helpers section:

1. Define `GSD_ERROR_CODES` as a frozen object with string keys mapping to string codes. Initial codes:

```javascript
const GSD_ERROR_CODES = Object.freeze({
  CONFIG_READ:     'CONFIG_READ',      // Failed to read config file
  CONFIG_PARSE:    'CONFIG_PARSE',     // Failed to parse config JSON
  CONFIG_MIGRATE:  'CONFIG_MIGRATE',   // Config migration failed
  CONFIG_WRITE:    'CONFIG_WRITE',     // Failed to write config file
  STATE_READ:      'STATE_READ',       // Failed to read state file
  STATE_WRITE:     'STATE_WRITE',      // Failed to write state file
  PHASE_READ:      'PHASE_READ',       // Failed to read phase directory/files
  PHASE_WRITE:     'PHASE_WRITE',      // Failed to write phase files
  LOCK_ACQUIRE:    'LOCK_ACQUIRE',     // Failed to acquire planning lock
  LOCK_STALE:      'LOCK_STALE',       // Stale lock detected and force-acquired
  GIT_EXEC:        'GIT_EXEC',         // Git command execution failed
  FILE_READ:       'FILE_READ',        // General file read failure
  FILE_WRITE:      'FILE_WRITE',       // General file write failure
  PARSE_ERROR:     'PARSE_ERROR',      // JSON/YAML/frontmatter parse failure
  COMMAND_DISPATCH:'COMMAND_DISPATCH', // Command routing/dispatch failure
  TEMPLATE_RENDER: 'TEMPLATE_RENDER', // Template rendering failure
  VALIDATION:      'VALIDATION',       // Input validation failure
});
```

2. Define `GsdError` class:

```javascript
class GsdError extends Error {
  /**
   * @param {string} code - Error code from GSD_ERROR_CODES
   * @param {string} message - Human-readable error message
   * @param {object} [options]
   * @param {object} [options.context] - Structured context (file path, operation, etc.)
   * @param {Error}  [options.cause] - Original error that caused this one
   */
  constructor(code, message, { context, cause } = {}) {
    super(message);
    this.name = 'GsdError';
    this.code = code;
    this.context = context || null;
    this.cause = cause || null;
  }
}
```

3. Add both to module.exports at the bottom of the file. Add `GsdError` and `GSD_ERROR_CODES` to the existing module.exports object.

Do NOT modify any existing catch blocks in this task — that is Plan 2 and Plan 3.
</action>

<action>
Add a new describe block to tests/core.test.cjs for GsdError. Import `GsdError` and `GSD_ERROR_CODES` in the existing require() block at the top of the file.

Add these test cases inside `describe('GsdError', () => { ... })`:

1. **'constructs with code and message'** — Create `new GsdError('CONFIG_READ', 'bad config')`, assert `err.code === 'CONFIG_READ'`, `err.message === 'bad config'`, `err.name === 'GsdError'`, `err instanceof Error`.

2. **'stores context object'** — Create with `{ context: { path: '/tmp/config.json', operation: 'read' } }`, assert `err.context.path === '/tmp/config.json'`.

3. **'stores cause error'** — Create with `{ cause: new Error('ENOENT') }`, assert `err.cause instanceof Error`, `err.cause.message === 'ENOENT'`.

4. **'defaults context and cause to null'** — Create without options, assert `err.context === null`, `err.cause === null`.

5. **'stores both context and cause'** — Create with both, assert both are present.

Add a separate describe block `describe('GSD_ERROR_CODES', () => { ... })`:

1. **'is a frozen object'** — `assert.ok(Object.isFrozen(GSD_ERROR_CODES))`.
