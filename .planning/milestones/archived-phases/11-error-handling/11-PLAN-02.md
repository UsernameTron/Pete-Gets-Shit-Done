**Part A: Add a debug logging helper at the top of core.cjs (after GsdError class, before path helpers)**

Create a module-scoped helper for debug-level diagnostics that writes to stderr only when GSD_DEBUG env var is set:

```javascript
function debugLog(code, message, context) {
  if (process.env.GSD_DEBUG) {
    const prefix = `[GSD:${code}]`;
    const ctx = context ? ` ${JSON.stringify(context)}` : '';
    fs.writeSync(2, `${prefix} ${message}${ctx}\n`);
  }
}
```

Add `debugLog` to module.exports.

**Part C: Audit and remediate ALL other catch blocks in core.cjs**

Go through every catch block in core.cjs. For each, apply one of these treatments:

1. **Already has adequate comment (e.g., `/* intentionally empty */`)** — Standardize the comment format to `/* intentional: [reason] */`. Example: `} catch { /* intentional: file may disappear between readdir and stat */ }`

2. **Empty with no comment** — Add either:
   - An `/* intentional: [reason] */` comment if the silence is correct behavior
   - A `debugLog()` call if the failure contains useful diagnostic information

3. **Already handles error (e.g., `catch (err) { ... }`)** — Leave as-is.
