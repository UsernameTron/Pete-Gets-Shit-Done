  <action>
Create `scripts/generate-gap-analysis.cjs` -- a CommonJS Node.js script (zero dependencies, uses only `fs` and `path`) that:

1. Reads `coverage/coverage-final.json` (Istanbul format from c8)
2. For each file entry, calculates:
   - Line coverage %: `coveredLines / totalLines * 100`
   - Branch coverage %: `coveredBranches / totalBranches * 100`
   - Function coverage %: `coveredFunctions / totalFunctions * 100`
   - Statement coverage %: `coveredStatements / totalStatements * 100`
3. Classifies each module into a priority tier using this mapping:
   - **Security-Critical**: Files matching `security.cjs`, `*prompt-injection*`, `*base64-scan*`, `*secret-scan*`, `gsd-prompt-guard.js`
   - **Operational**: Files matching `core.cjs`, `commands.cjs`, `state.cjs`, `phase.cjs`, `init.cjs`, `verify.cjs`, `gsd-tools.cjs`, `install.js`, `gsd-workflow-guard.js`
   - **Utility**: Everything else (template, frontmatter, model-profiles, profile-*, roadmap, milestone, uat, workstream, gsd-statusline, gsd-check-update, gsd-context-monitor, build-hooks)
4. Sorts modules within each tier by line coverage ascending (lowest coverage first = highest priority gap)
5. Writes `docs/coverage-gaps.md` with this structure:

```markdown
# Coverage Gap Analysis

**Generated:** [ISO date]
**Source:** coverage/coverage-final.json from `npm run test:coverage`
**Total modules measured:** [count]

## Priority Ranking

Modules ranked by coverage gap severity within each tier.
Priority: Security-Critical > Operational > Utility.

### Security-Critical

| Module | Lines | Branches | Functions | Gap Priority |
|--------|-------|----------|-----------|-------------|
| [name] | [pct]% | [pct]% | [pct]% | [HIGH/MEDIUM/LOW based on line coverage: <50% HIGH, 50-80% MEDIUM, >80% LOW] |

### Operational

[same table format]

### Utility

[same table format]

## Shell Script Inventory

Per D-02: binary tested/untested status only. No line-coverage numbers for bash.

| Script | Test File | Status |
|--------|-----------|--------|
| governance/scripts/health-check.sh | governance/tests/test_health_check.sh | TESTED |
| governance/scripts/install-plugins.sh | governance/tests/test_install_plugins.sh | TESTED |

| scripts/prompt-injection-scan.sh | tests/prompt-injection-scan.test.cjs | TESTED |
| scripts/secret-scan.sh | tests/security-scan.test.cjs | TESTED |

## Summary

- **Modules with 0% line coverage:** [list]
- **Modules below 80% line coverage:** [list]
- **Security-critical gaps:** [count with details]
- **Recommended Phase 3 priority order:** [ordered list]

## Baseline Reference

See [coverage-baseline.md](coverage-baseline.md) for the full per-module coverage snapshot.
```
