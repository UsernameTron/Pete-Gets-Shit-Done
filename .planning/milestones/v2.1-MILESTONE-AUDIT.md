## Addendum: Item 4 False Positive Correction (2026-04-10)

**Original finding (Item 4):** "12 commands in source not in installer" — flagged by Phase 36 as an Info-severity deployment gap.

**Correction:** This finding is a methodology false positive. All 12 commands ARE registered in `bin/install.js` and ARE installed to `~/.claude/commands/gsd/` at install time.

### Root Cause: Category Error in Phase 36 Audit

GSD has a two-directory architecture for executable files:

| Directory | Contents | Count | Installed by |
|-----------|----------|-------|--------------|
| `~/.claude/commands/gsd/` | User-facing slash commands (e.g., `/gsd:plan-phase`) | 62 files | `bin/install.js` |
| `~/.claude/get-shit-done/workflows/` | Internal orchestration workflows (not user-invokable) | 56 files | Copied to lib path, never registered as commands |

The Phase 36 audit compared **source workflows/** against the installer's **commands/gsd/** registrations. This is a category error — commands and workflows are different artifacts with different installation paths. Workflows are internal orchestration logic consumed by the execution engine; they are not slash commands and were never intended to appear in the installer's command registration block.

### Verification Proof

`bin/install.js` lines 4465-4467 and 4476-4478 register all 12 commands that were flagged. Post-install inspection of `~/.claude/commands/gsd/` confirms every one of the 12 is present.

### Net Effect on Tech Debt Count

v2.1 has **4 real tech debt items**, not 5. Item 4 is retracted. The remaining 4 items (missing artifacts backfilled during audit, stale checkboxes, Nyquist N/A, non-GSD agent tier mismatches) stand as originally documented.
