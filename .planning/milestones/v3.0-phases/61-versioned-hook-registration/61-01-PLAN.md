<objective>
Guarantee a fresh clone registers the full runtime hook set the repo ships — 8 sources today (7 `hooks/*.js` + `.claude/hooks/lesson-capture-gate.cjs`) — with none silently unwired, by adding a versioned declarative registry template and a filesystem-derived contract test that fails on drift.

Purpose: The v2.9 close-out flagged that hook wiring lived only in imperative installer code (`bin/install.js`) with nothing test-locking the shipped sources to their registrations. A 9th hook could ship unregistered and no test would notice. This phase makes the registration set an auditable, versioned, diffable artifact and fails CI the moment a shipped source is not accounted for.
