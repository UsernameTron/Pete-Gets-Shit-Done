<objective>
Implement {{GSD_VERSION}} template substitution in build-hooks.js so that hooks/dist/ files contain the actual package version string.

Purpose: All 7 hook source files carry the version template placeholder on line 2, but build-hooks.js copies them verbatim without substitution. The gsd-check-update.js staleness check explicitly skips hooks with unsubstituted templates, making version tracking inoperative on unbuilt hooks. Note: bin/install.js already performs this substitution at install time, so this fix adds defense-in-depth at the build step, ensuring dist/ hooks always have real versions.

Output: Updated build-hooks.js with version substitution, updated tests.
</objective>
