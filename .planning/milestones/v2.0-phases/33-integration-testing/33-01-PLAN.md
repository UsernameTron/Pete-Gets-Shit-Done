# PLAN -- Phase 33.1: E2E Intelligence Pipeline + Performance + Coverage

## Objective

Create an end-to-end integration test that exercises the full intelligence pipeline (classify -> route -> execute -> record -> learn) and a performance benchmark proving dynamic routing adds <5ms overhead. Verify coverage gates for all new modules.

## Architecture Constraints

- **Zero external dependencies**: `node:test` + `node:assert/strict` only.
- **E2E harness**: Use existing `tests/e2e/fixtures.cjs` and `tests/e2e/assertions.cjs`.
- **No mocked LLM calls**: Test the init command pipeline, not actual model invocations. The intelligence pipeline lives entirely within `gsd-tools init` commands.
- **Performance**: Use `process.hrtime.bigint()` for nanosecond-precision timing. Run multiple iterations (100+) and assert median < 5ms.
- **Coverage**: Run c8 with existing `.c8rc.json` config and verify module-level thresholds.

## Task 2: Performance Benchmark -- INTEL-20

Create `tests/perf/routing-benchmark.test.cjs`.

### Directory Setup

Create `tests/perf/` directory. This is a new test subdirectory.

### Benchmark Structure

```js
'use strict';
const { describe, it } = require('node:test');
const assert = require('node:assert/strict');
const path = require('path');
const fs = require('fs');
const os = require('os');
```

### Approach

Do NOT shell out to gsd-tools for performance testing -- the overhead of `execFileSync` would dominate. Instead, require the modules directly:

```js
const { classifyTask } = require('../../get-shit-done/bin/lib/classify.cjs');
const { dynamicSelect } = require('../../get-shit-done/bin/lib/model-profiles.cjs');
```

### Test Cases (~5 tests)

1. **classifyTask median < 2ms**: Create representative phaseInfo and planInventory objects. Run `classifyTask()` 200 times. Collect durations via `process.hrtime.bigint()`. Compute median. Assert median < 2ms (2_000_000n nanoseconds).

2. **dynamicSelect median < 2ms**: Create taskContext with classification signals. Run `dynamicSelect()` 200 times. Assert median < 2ms.

3. **Combined classify+route median < 5ms**: Run classify then dynamicSelect sequentially 200 times. Assert combined median < 5ms (5_000_000n nanoseconds). This is the INTEL-20 acceptance criterion.

4. **No GC pressure from routing**: Run 1000 iterations of classify+route. Measure total heap growth via `process.memoryUsage().heapUsed` before/after. Assert heap growth < 5MB (no meaningful memory leak per iteration).

5. **Static routing is near-zero overhead**: Run `resolveModelInternal()` with `routing_strategy: 'static'` 200 times. Assert median < 0.5ms. This proves the static path (v1.9 behavior) has no regression.

### Helper

```js
function median(arr) {
  const sorted = [...arr].sort((a, b) => (a < b ? -1 : a > b ? 1 : 0));
  const mid = Math.floor(sorted.length / 2);
  return sorted.length % 2 ? sorted[mid] : (sorted[mid - 1] + sorted[mid]) / 2n;
}
```

### Important: Warm-up

Run 10 warm-up iterations before measuring to allow V8 JIT compilation. This prevents the first-run penalty from skewing results.
