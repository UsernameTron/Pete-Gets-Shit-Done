# PLAN — Phase 32.3: History Integration — dynamicSelect + init.cjs Wiring

## Objective

Wire execution history into two integration points: (1) `dynamicSelect()` in model-profiles.cjs consults history when `routing_strategy: 'auto'` (INTEL-16), and (2) init.cjs supplies historical failure rate to `classifyTask()` context (INTEL-18).

## Architecture Decision

- `model-profiles.cjs` is Layer 0, `history.cjs` is Layer 2 — model-profiles.cjs CANNOT import history.cjs directly (would violate layer constraint)
- Solution: Pass history data through the `taskContext` object. The init commands (Layer 3) read history and inject it into taskContext before calling `resolveModelInternal()`.
- This preserves the same lazy-require pattern used for classify.cjs in Phase 31.

## Task 1: Extend taskContext with history data in init.cjs (INTEL-18)

In `get-shit-done/bin/lib/init.cjs`, in both `cmdInitExecutePhase()` and `cmdInitPlanPhase()`:

After the existing `taskContext` computation, add history lookup:

```js
// Historical failure rate for classification and routing (INTEL-18)
let failureRate = null;
let historyHints = null;
if (config.adaptive || config.routing_strategy === 'auto') {
  try {
    const history = require('./history.cjs');
    const phaseRecords = history.queryHistory(cwd, {
      phaseRange: [phaseNum, phaseNum],
    });
    if (phaseRecords.total > 0) {
      const failures = phaseRecords.records.filter(r => r.outcome === 'fail').length;
      failureRate = failures / phaseRecords.total;
    }
    // History hints for dynamic routing (INTEL-16)
    if (config.routing_strategy === 'auto') {
      const patterns = history.detectPatterns(cwd);
      historyHints = {
        failureRate,
        patterns: patterns.patterns || [],
        summary: patterns.summary || null,
      };
    }
  } catch {
    // History module unavailable or history file missing — degrade gracefully
  }
}
```

Then update the `classContext` to use the computed `failureRate`:
```js
const classContext = {
  reqIds: phase_req_ids,
  failureRate, // Was null, now supplied from history
};
```

And inject `historyHints` into `taskContext`:
```js
if (historyHints) {
  taskContext.historyHints = historyHints;
}
```

## Task 2: Extend dynamicSelect() to use history hints (INTEL-16)

In `get-shit-done/bin/lib/model-profiles.cjs`, in `dynamicSelect()`:

After the existing tier mapping logic and before the return, add history-based promotion:

```js
// History-based tier promotion (INTEL-16)
// When routing_strategy is 'auto' and history shows high failure rates,
// promote the tier to reduce failures
if (taskContext?.historyHints) {
  const hints = taskContext.historyHints;
  // Check if this specific agent has a tier mismatch pattern
  const agentPattern = hints.patterns.find(
    p => p.type === 'agent_tier_mismatch' && p.agent === agentType
  );
  if (agentPattern && effectiveTier !== 'quality') {
    effectiveTier = 'quality';
    rationale += ` history-promoted=true (${agentPattern.evidence})`;
  }
  // Check if the current phase has high failure rate
  const phasePattern = hints.patterns.find(
    p => p.type === 'failing_phase'
  );
  if (phasePattern && hints.failureRate > 0.3 && effectiveTier === 'budget') {
    effectiveTier = 'balanced';
    rationale += ` phase-promoted=true (failure_rate=${hints.failureRate})`;
  }
}
```

Note: This does NOT require history.cjs import — it reads from the `taskContext.historyHints` object that init.cjs already populated. Layer constraint preserved.

The `rationale` variable needs to change from `const` to `let` to allow mutation.
