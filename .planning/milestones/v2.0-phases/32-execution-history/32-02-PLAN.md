# PLAN — Phase 32.2: History CLI Commands & Hygiene

## Objective

Add `gsd-tools history list|stats|prune` CLI commands and auto-rotation logic to history.cjs. When the JSONL file exceeds 1000 records, `recordExecution()` auto-rotates to keep the latest 500.

## Task 1: Add auto-rotate to recordExecution() in history.cjs (INTEL-17)

After the append operation in `recordExecution()`, add rotation check:

```js
// Auto-rotate: keep latest 500 when file exceeds 1000 records
const records = parseJsonlSafe(historyPath);
if (records.length > 1000) {
  const kept = records.slice(-500);
  fs.writeFileSync(historyPath, kept.map(r => JSON.stringify(r)).join('\n') + '\n');
}
```

Export rotation constants for testability:
```js
const ROTATION_THRESHOLD = 1000;
const ROTATION_KEEP = 500;
```

## Task 4: Add pruneHistory(cwd, keepCount) to history.cjs

Manual prune function:
1. Read all records
2. Keep the latest `keepCount` records (default: 500)
3. Rewrite the file
4. Return `{ pruned: originalCount - keepCount, remaining: keepCount }`

If `keepCount >= records.length`, return `{ pruned: 0, remaining: records.length }`.

## Task 5: Add `history` case to gsd-tools.cjs CLI router

In the main switch/case block (after `history-digest` at line 587), add:

```js
case 'history': {
  const history = require('./lib/history.cjs');
  const subcommand = args[1];
  if (subcommand === 'list') {
    const flags = parseNamedArgs(args, ['agent', 'outcome', 'limit'], []);
    const filters = {};
    if (flags.agent) filters.agent = flags.agent;
    if (flags.outcome) filters.outcome = flags.outcome;
    if (flags.limit) filters.limit = parseInt(flags.limit, 10);
    const result = history.queryHistory(cwd, filters);
    history.formatHistoryList(result.records, raw);
  } else if (subcommand === 'stats') {
    const result = history.queryHistory(cwd, {});
    const patterns = history.detectPatterns(cwd);
    history.formatHistoryStats(result.records, patterns, raw);
  } else if (subcommand === 'prune') {
    const keepFlag = parseNamedArgs(args, ['keep'], []);
    const keepCount = keepFlag.keep ? parseInt(keepFlag.keep, 10) : 500;
    const result = history.pruneHistory(cwd, keepCount);
    if (raw) {
      console.log(JSON.stringify(result));
    } else {
      console.log(`Pruned ${result.pruned} records. ${result.remaining} remaining.`);
    }
  } else {
    error('Unknown history subcommand. Available: list, stats, prune');
  }
  break;
}
```

Note: Use lazy `require('./lib/history.cjs')` inside the case block to avoid loading history.cjs for every gsd-tools invocation.
