# Requirements: get-shit-done

**Defined:** 2026-04-17
**Core Value:** Predictable, high-quality execution at scale -- turning ambiguous prompts into shipped, tested, documented code without skipped steps.

## v2.6 Requirements

Requirements for milestone v2.6 Developer Experience. Each maps to roadmap phases.

### Install

- [x] **INST-01**: User can run a single command from a fresh git clone to get a fully working GSD install
- [x] **INST-02**: Script runs npm install and verifies node_modules populated
- [x] **INST-03**: Script creates symlinks in ~/.claude/commands/gsd/ for all GSD slash commands
- [x] **INST-04**: Script copies built hooks to ~/.claude/hooks/ or registers them in settings.json
- [x] **INST-05**: Script registers plugins in Claude Code plugin config
- [x] **INST-06**: Script copies lib/injection-patterns.json to required locations
- [x] **INST-07**: Script verifies install by running a health check and reporting pass/fail

### CI Watch

- [x] **CIWATCH-01**: User can run /gsd:ci-watch to start polling gh run list for the current branch
- [x] **CIWATCH-02**: Command polls on a configurable interval until all runs complete
- [x] **CIWATCH-03**: Command surfaces pass/fail results inline with run names and URLs
- [x] **CIWATCH-04**: On failure, command fetches workflow logs and diagnoses the failure
- [x] **CIWATCH-05**: On failure, command suggests specific fixes based on log analysis

### Sync Docs

- [x] **SDOCS-01**: User can run /gsd:sync-docs to update all project documentation
- [x] **SDOCS-02**: Command updates test counts, agent counts, command counts, coverage numbers
- [x] **SDOCS-03**: Command updates milestone status, phase history, architecture descriptions
- [x] **SDOCS-04**: Command updates README.md, CLAUDE.md, PROJECT.md, DEVOPS-HANDOFF.md
- [x] **SDOCS-05**: Command auto-generates/updates CHANGELOG.md entries from git history
- [x] **SDOCS-06**: Command reports what changed with a summary of updates made

## Future Requirements

None -- all scoped features are in v2.6.

## Out of Scope

| Feature | Reason |
|---------|--------|
| GUI installer | CLI-only project, no graphical installer needed |
| CI provider abstraction | GitHub Actions only, no Jenkins/GitLab/Circle support this milestone |
| Auto-trigger CI watch on push | Adds hook complexity for marginal value; explicit invocation is clearer |
| Doc sync for external docs | Only project-internal docs (README, CLAUDE.md, PROJECT.md, DEVOPS-HANDOFF, CHANGELOG) |
