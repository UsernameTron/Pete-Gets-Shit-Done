'use strict';
const path = require('path');

**gatherDailyState(planningDir):**
1. Try `readCheckpoint(planningDir)`. If non-null, add `_source: 'checkpoint'` and return.
2. If null, read STATE.md via `safeReadFile(path.join(planningDir, 'STATE.md'))`.
3. If STATE.md exists, extract frontmatter with `extractFrontmatter()`. Build state object:
   - `milestone` from frontmatter `milestone` field
   - `phase` from frontmatter progress or body regex matching `Phase: NN`
   - `phase_name` from body regex matching `Phase.*—\s*(.+)` or `Current focus:.*Phase \d+ — (.+)`
   - `plans` via `scanPlanStatus(planningDir, phase)` if phase > 0
   - `branch` and `commit` via `execGit(cwd, ...)` with safe defaults 'unknown'/'0000000'
   - `_stale: false`, `_ageHours: 0`, `_source: 'state'`
   - `next_action: ''`, `context_note: ''`
4. If neither exists, return `{ _source: 'none', milestone: '', phase: 0, phase_name: '', plans: { total: 0, completed: [], active: null, pending: [] }, branch: 'unknown', commit: '0000000', _stale: false, _ageHours: 0, next_action: '', context_note: '' }`.

**determineNextAction(state):**
Returns a string — the exact /gsd: command to run next.
Decision tree:
1. If `state._source === 'none'` → return `/gsd:new-project`
2. If `state.next_action` is truthy (checkpoint had explicit next) → return `state.next_action`
3. If `state.plans.total === 0` → return `/gsd:plan-phase ${state.phase}`
4. If `state.plans.active` is truthy → return `/gsd:execute-phase ${state.phase}`
5. If `state.plans.pending.length > 0` → return `/gsd:execute-phase ${state.phase}`
6. If `state.plans.completed.length === state.plans.total && state.plans.total > 0` → return `/gsd:verify-work ${state.phase}`
7. Fallback → return `/gsd:progress`

**formatDashboard(state):**
Build multiline string. Sections:
```
# Daily Dashboard

**Milestone:** {state.milestone || '(none)'}
**Phase:** {state.phase} — {state.phase_name || '(unnamed)'}
**Branch:** {state.branch}

## Plan Progress
{state.plans.completed.length}/{state.plans.total} plans complete
Completed: {state.plans.completed.join(', ') || 'none'}
Active:    {state.plans.active || 'none'}
Pending:   {state.plans.pending.join(', ') || 'none'}

## Next Action
{nextAction}

[warnings section if any]
```

Warnings (appended at bottom):
- If `state._gitDirty` is true → append `\nWARNING: dirty working tree — uncommitted changes detected`
- If `state._stale` is true → append `\nWARNING: checkpoint is stale ({state._ageHours}h old) — run /gsd:checkpoint to refresh`
- If `state._source === 'none'` → replace main body with `No project state found. Run /gsd:new-project to initialize.`

Git dirty detection: In gatherDailyState, after reading git branch/commit, also run `execGit(cwd, ['status', '--porcelain'])`. If stdout is non-empty, set `_gitDirty: true`.
