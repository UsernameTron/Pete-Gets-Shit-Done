Lens findings (full structured outputs preserved in the run's scratchpad; synthesized in Phase 3): the autonomy spine admits human input at five altitudes (intent → spec → scope approval → egress approval → error recovery); the ship spine is a reversible front half (nothing irreversible before milestone completion) and a mixed back half where `finalize`'s two pushes and `complete-milestone`'s tag-push are the egress points; enforcement runs on four non-overlapping planes (repo-session hooks, installed workstation hooks, unregistered built hooks, remote CI/branch-protection) — with the lesson-capture Stop gate built-but-registered-nowhere as the standing gap.
