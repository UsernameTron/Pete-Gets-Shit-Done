### Autonomy spine — five altitudes of human input

Human input enters GSD at five distinct altitudes, each with a different legitimacy profile:

1. **Intent** — free text into the do router. Empty input halts (`get-shit-done/workflows/do.md:14`); genuinely ambiguous input asks with the top 2-3 routes (`do.md:62`); everything else dispatches ungated, with a routing banner substituting for confirmation (`do.md:87`).
2. **Spec** — discuss-phase per-area questioning (`get-shit-done/workflows/discuss-phase.md:643`) or smart-discuss proposal tables.
3. **Scope approval** — idea-to-shipped GATE 1 (`get-shit-done/workflows/idea-to-shipped.md:120`), autonomous's gap decisions.
4. **Egress approval** — GATE 2 (`idea-to-shipped.md:230`) and wrap-and-sync's single commit/push gate (`get-shit-done/workflows/wrap-and-sync.md:104`).
5. **Failure triage** — blocker menus (`get-shit-done/workflows/autonomous.md:488`) and pause-work handoffs (`idea-to-shipped.md:300`).

daily-startup proves zero gates can be legitimate: read-only plus one idempotent write, stated in its own purpose block.

Three autonomy mechanisms compose implicitly:

- (a) yolo-mode template conditionals in transition and complete-milestone;
- (b) the `--auto` flag, plus `workflow._auto_chain_active` (ephemeral chain state, persisted to survive compaction; `get-shit-done/bin/lib/config.cjs:26`), plus `workflow.auto_advance` (persistent preference, default false; `config.cjs:122`);
- (c) orchestrator workflows (autonomous.md, idea-to-shipped.md) that deliberately avoid the flag and chain via flat Skill() calls with --no-transition to retain routing control.

The composition has one verified hazard: `get-shit-done/workflows/plan-phase.md:738` reads the auto_advance config unconditionally, so on a project with `auto_advance=true` (the yolo new-project default path), plan-phase self-chains into execute-phase before idea-to-shipped's GATE 1 ever renders — mechanism (b) tunnels under mechanism (c)'s gates. VERIFIED (`idea-to-shipped.md:85` invokes plan-phase without --auto; `plan-phase.md:735-741` chains anyway).

Invariants that hold across discuss-plan-execute-verify-ship:

- Merge is never automated — no merge API call anywhere; branch protection holds remote-side.
- Nothing leaves the machine before an explicit gate.
- Auto-advance requires verification passed with no gaps (`get-shit-done/workflows/execute-phase.md:789`).
- Automatic gap closure is capped at exactly 1 retry everywhere.
- Human-action checkpoints stop even in full auto (`get-shit-done/references/checkpoints.md:11`).
- The chain flag self-clears on any manual invocation and force-clears at workstream and milestone boundaries (`get-shit-done/workflows/transition.md:529`, `:583`).
- Each stage validates its predecessor's on-disk artifact (has_context, has_plans, VERIFICATION status), so chains survive compaction.
- Failures stop-and-report with resumable state, never auto-debug.

### Enforcement topology — four planes that do not overlap

**Plane 1 — runtime hooks** (`hooks/*.js`, 6 sources, built to `hooks/dist`, installed to the user scope by `bin/install.js:4769-4933`). Two blocking: gsd-prompt-guard denies Write/Edit into `.planning/` on 23 injection-detection regexes plus invisible Unicode, fail-closed exit 2 (`hooks/gsd-prompt-guard.js:105`); gsd-config-protection denies Write/Edit to ~32 linter/formatter configs (`hooks/gsd-config-protection.js:90`). Three advisory (context-monitor threshold warnings, cost-tracker JSONL, check-update background check) plus the statusline. Both blockers are live in this audit container.

**Plane 2 — installed governance** (`governance/templates/global/settings-hooks.json`, merged into user settings only by installGovernance, `bin/install.js:4640`). Six blocking PreToolUse Bash gates — no commit on main (`:20`), no staging private files (`:30`), required-docs-exist (`:40`), staged secrets (`:50`), nested .git (`:60`), dirty-tree push (`:70`) — plus the Stop uncommitted-files block (`:88-98`). None of it runs on bare clones or in this container.

**Plane 3 — repo session** (`.claude/settings.json`). Exactly one hook: SubagentStop routed to `scripts/gsd-agent-health-check.sh`, purely advisory (always exit 0), which fired on every subagent completion this run and logged real DRIFT lines to `.planning/agent-health.log`.

**Plane 4 — remote**. Branch protection requires 5 checks (test x3, governance, docs-integrity); `check-doc-drift` runs inside the ubuntu/22 test leg (`.github/workflows/test.yml:53-56`). Notable: `security-scan.yml:13` runs four scans on PRs (prompt-injection, base64, secret, coverage-artifact) but is NOT among the 5 required contexts — it fails its own workflow and is skippable at merge. The only context-independent plane is this one.

**The unregistered gate.** `.claude/hooks/lesson-capture-gate.cjs` is a complete blocking Stop gate — 605 lines, exit 2 at `:578`, tiered signal matcher, tests, a debug log, and a Session Exemptions escape hatch — registered in no settings file anywhere (repo settings hold only the SubagentStop entry; the container's user settings hold only the five runtime hooks; the governance template registers an inline uncommitted-files command instead). `tasks/lessons.md:18` records it shipping in PR #34 and sitting inert 3 days and all of v2.2; it is still unwired, and `wrap-and-sync.md:2` explicitly performs the lesson check manually in its place. The standing rule it generated: hook code without a verified registration is a no-op with test coverage.

**The 2026-04-10 false-positive class: enforcement racing explicit operator intent.** The governance Stop gate (`settings-hooks.json:93`) blocks session end on any dirty tree. It cannot distinguish "forgot to commit" from "operator explicitly deferred the commit for review," and on 2026-04-10 it forced a commit while Pete was mid-diff-review (`tasks/lessons.md:19`). The prescribed fix — a `.planning/.review-pending` sentinel — was implemented at the workflow level only (`wrap-and-sync.md:92-98`, contract-locked by `tests/wrap-and-sync.test.cjs:85-88`); the hook still does not check it. The same FP-management pattern recurs on every plane: the CI scan allowlist accretes per-milestone entries v2.3 through v2.7 (`scripts/prompt-injection-scan.sh:68-91`), doc-drift needed a 0.1 epsilon after flagging cross-OS coverage variance (`lessons.md:23`), and matrix check-name truncation nearly bricked merges (`lessons.md:24`). The rule for fix-authors in this audit's blueprints: every new enforcement automation ships with an operator-intent escape hatch and a registration-verification step, or it will either fight the operator or sit inert.

### Internal precedents — the de-prompting doctrine

The precedents lens confirmed thirteen reusable implementations of it, at four altitudes: runtime substitution (code answers instead of user answers), flag- and config-scoped suppression, judgment tiering, and enforcement instead of asking. ## Phase 3 — The Friction Ledger

**Headroom: 349 sites; 64 AUTOMATE + 220 DEFAULT+LOG = 284 automatable; 65 GATE-KEEP; 349 VERIFIED / 0 INFERRED.**

Eighty-one percent of GSD's human-interaction surface can be removed outright or converted to a logged default without touching a single irreversible operation. Every row below was re-opened at its cited location before classification; no row rests on inference.
