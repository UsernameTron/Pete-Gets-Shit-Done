<objective>
Run a full ecosystem audit across every GSD agent in `./agents/` (frontmatter schema, tool/permission consistency, P0 hygiene compliance, description quality, naming collisions, install drift between repo and `~/.claude/agents/`). Produces a BLOCK/FLAG/PASS verdict with a committable report at `.planning/ecosystem/ECOSYSTEM-REPORT.md`.

**This command spawns the `gsd-ecosystem-auditor` agent and post-processes its output.** It does not contain audit logic itself — all schema parsing, tool inspection, hygiene grepping, and drift diffing lives in the agent. This command handles: flag parsing, spawning, branch/commit housekeeping, and user-facing summary.

**Convention note:** Like `/gsd:audit-deps`, this command does NOT have a companion workflow file at `~/.claude/get-shit-done/workflows/audit-agents.md`. The orchestration is simple enough to live inline. If this command grows its own pre/post processing logic (beyond flag parsing), extract to a workflow file at that time.
</objective>

<arguments>
Parse `$ARGUMENTS` for these flags. Missing flags default to the behaviors noted.

- `--no-commit` — Do NOT auto-commit `ECOSYSTEM-REPORT.md` after the audit. Default: auto-commit on a `chore/ecosystem-audit-<timestamp>` branch.
- `--quiet` — Suppress the SUMMARY echo to the user. Default: echo the SUMMARY block after the audit completes.
- Any other argument is ignored with a warning.
</arguments>

<process>

## Step 1: Pre-flight checks

Verify we're in a git repo and the current directory has an `./agents/` directory with at least one `gsd-*.md` file:

```
Bash: git rev-parse --show-toplevel 2>/dev/null
```

If this fails, the project is not a git repo. Warn the user and continue anyway — the audit itself does not require git, only the auto-commit does. If the user passed `--no-commit`, a missing git repo is fine.

Check for the agents directory:

```
Bash: test -d agents && echo "agents dir exists" || echo "agents dir missing"
Glob: agents/gsd-*.md
```

If the `agents/` directory does not exist OR zero `gsd-*.md` files are found, print:

```
No GSD agents found in ./agents/. /gsd:audit-agents expects a plugin repository with:
  agents/gsd-*.md

This command is for auditing the GSD plugin's own agent roster, not arbitrary project helpers.
```

…and stop. Do not spawn the agent.

## Step 2: Spawn the auditor agent

Invoke `gsd-ecosystem-auditor` via the Task tool with `subagent_type: gsd-ecosystem-auditor`.

Prompt the agent with:

```
Perform a full ecosystem audit of the GSD agent roster in the current working directory.

Audit scope: frontmatter schema, tool/permission consistency, hygiene compliance, description quality, naming collisions, install drift.

Source directory: ./agents/
Installed directory: ~/.claude/agents/

Write your structured report to .planning/ecosystem/ECOSYSTEM-REPORT.md following the format specified in your role instructions. Echo the SUMMARY block to stdout so I can surface it to the user.

Respect all rules in your anti_patterns section. Specifically: no file modifications outside the single report file, no roster-composition opinions, no hedged verdicts.
```

Wait for the agent to complete. Capture its response text.

## Step 3: Verify the report exists

```
Bash: test -f .planning/ecosystem/ECOSYSTEM-REPORT.md && echo "report exists" || echo "report missing"
```

If the report is missing, the agent failed. Print the agent's response text verbatim so the user can diagnose, and stop. Do NOT proceed to commit.

## Step 4: Extract and display the SUMMARY block (unless --quiet)

If `--quiet` was NOT passed:

```
Bash: sed -n '/--- SUMMARY ---/,/--- FRONTMATTER FINDINGS ---/p' .planning/ecosystem/ECOSYSTEM-REPORT.md
```

Print the result to the user so they see the verdict immediately.

## Step 5: Commit the report (unless --no-commit)

If `--no-commit` was passed, skip this step and tell the user: "Report written to `.planning/ecosystem/ECOSYSTEM-REPORT.md` (not committed, per --no-commit)."

Otherwise:

```
Bash: git rev-parse --abbrev-ref HEAD
```

If the current branch is `main` or `master`, create a new branch:

```
Bash: git checkout -b chore/ecosystem-audit-$(date +%Y%m%d-%H%M%S)
```

Then:

```
Bash: git add .planning/ecosystem/ECOSYSTEM-REPORT.md
Bash: git commit -m "chore: ecosystem audit report

Verdict: <PASS|FLAG|BLOCK>
Generated by /gsd:audit-agents
"
```

Print the resulting commit hash and branch name to the user.

## Step 6: Extract the overall verdict and exit appropriately

Parse the verdict from the SUMMARY:

```
Bash: grep -m1 "^Overall verdict:" .planning/ecosystem/ECOSYSTEM-REPORT.md | awk '{print $3}'
```

Report to the user in one line:

- `PASS` → "Ecosystem audit: PASS. No action required."
- `FLAG` → "Ecosystem audit: FLAG. Review `.planning/ecosystem/ECOSYSTEM-REPORT.md` for non-blocking issues."
- `BLOCK` → "Ecosystem audit: BLOCK. `.planning/ecosystem/ECOSYSTEM-REPORT.md` contains critical issues that should be fixed before shipping."

</process>

<examples>

**Clean run (default):**
```
/gsd:audit-agents
```
→ Spawns agent, writes report, commits on `chore/ecosystem-audit-<ts>` branch, echoes SUMMARY + one-line verdict.

**Rapid iteration (no commit):**
```
/gsd:audit-agents --no-commit
```
→ Spawns agent, writes report, echoes SUMMARY, leaves report uncommitted for the user to decide.

**CI-friendly (quiet + no commit):**
```
/gsd:audit-agents --no-commit --quiet
```
→ Spawns agent, writes report, prints only the one-line verdict. Useful inside larger orchestration.

</examples>

<anti_patterns>
<what_not_to_do>
1. **Do NOT run audit checks directly in this command file.** All audit logic lives in `gsd-ecosystem-auditor`. This file is orchestration only.
2. **Do NOT parse the DETAILED FINDINGS section.** It is optional enrichment for humans; downstream tooling uses only the content between `=== GSD ECOSYSTEM AUDIT REPORT ===` and `=== END REPORT ===`.
3. **Do NOT commit directly to main/master** even if the pre-commit hook is disabled. Always branch first.
4. **Do NOT try to auto-fix BLOCK verdicts.** This command reports; it does not remediate. Remediation is a separate phase (reinstall plugin, backfill hygiene sections, etc.).
5. **Do NOT run if no agents directory is found.** Spawning the agent for a non-plugin repository wastes tokens. Short-circuit in Step 1.
6. **Do NOT audit `.claude/agents/` (project-local helpers).** That scope belongs to a separate project-agent audit. This command is GSD-plugin-roster only.
</what_not_to_do>
</anti_patterns>
